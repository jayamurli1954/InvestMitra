Good idea. Here are the manual commands:

**Terminal 1 - Backend:**

Open Command Prompt or PowerShell and run:

```bash
cd C:\Users\Dell\investment_framework\backend
conda activate investenv
uvicorn server:app --reload --host 0.0.0.0 --port 8000
```

Wait for it to show:
```
Application startup complete.
```

**Terminal 2 - Frontend:**

Open a new Command Prompt or PowerShell and run:

```bash
cd C:\Users\Dell\investment_framework\frontend
conda activate investenv
npm start
```

Wait for it to show:
```
webpack compiled successfully
```

Then open browser to: `http://localhost:3000`

**To stop:**
- Press `Ctrl+C` in backend terminal
- Press `Ctrl+C` in frontend terminal

This is reliable and will work every time. Use this approach while we figure out the batch/script issue later.
