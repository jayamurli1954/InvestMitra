# InvestPro - Installation Guide for Desktop App

## How to Install InvestPro as a Standalone Desktop Application

Your InvestPro investment framework can be installed as a Progressive Web App (PWA) on your laptop/desktop, giving you a native app-like experience without downloading any executables.

---

## 🖥️ Installation Instructions by Browser

### **Google Chrome / Microsoft Edge / Brave**

1. **Open the App:**
   - Navigate to your InvestPro app URL in Chrome/Edge/Brave
   - Example: `http://localhost:3000` (for local) or your deployed URL

2. **Install the App:**
   - **Method 1 - Install Icon:**
     - Look for the **Install icon** (⊕ or computer icon) in the address bar (right side)
     - Click the icon → Click "Install"
   
   - **Method 2 - Menu Option:**
     - Click the three dots menu (⋮) in the top-right corner
     - Select **"Install InvestPro..."** or **"Install app..."**
     - Click "Install" in the confirmation dialog

3. **Launch the App:**
   - After installation, InvestPro will open in a standalone window
   - You can find it in:
     - **Windows:** Start Menu → Search "InvestPro"
     - **Mac:** Applications folder or Launchpad
     - **Linux:** Application menu

4. **Create Desktop Shortcut:**
   - Right-click the app icon in taskbar/dock
   - Select "Pin to taskbar" (Windows) or "Keep in Dock" (Mac)

---

### **Mozilla Firefox**

Firefox doesn't fully support PWA installation, but you can:

1. **Create Desktop Shortcut:**
   - Open the app URL
   - Click the three-line menu (☰) → "More Tools" → "Page Actions"
   - Select "Add to Desktop"
   
2. **Or Bookmark for Quick Access:**
   - Press `Ctrl+D` (Windows/Linux) or `Cmd+D` (Mac)
   - Save to Bookmarks Bar for easy access

---

### **Safari (Mac)**

1. **Add to Dock:**
   - Open the app in Safari
   - In the menu bar: **File** → **Add to Dock**
   - The app icon will appear in your Dock

2. **Or use Chrome/Edge:**
   - For better PWA experience on Mac, use Chrome or Edge browsers

---

## ✅ Benefits of Installing as Desktop App

1. **Native App Experience:**
   - Opens in its own window (no browser tabs clutter)
   - Has its own icon in taskbar/dock
   - Appears in app switcher (Alt+Tab / Cmd+Tab)

2. **Quick Access:**
   - Launch directly from Start Menu/Applications
   - Pin to taskbar for instant access
   - Works like any other desktop app

3. **Better Performance:**
   - Dedicated window without browser overhead
   - Faster startup times
   - Background updates supported

4. **Offline Capable:**
   - Basic caching for faster loading
   - Works with intermittent connectivity

## 🔄 How to Uninstall

### **Chrome / Edge / Brave:**
1. Open the app
2. Click the three dots (⋮) in the title bar
3. Select "Uninstall InvestPro..." → Confirm

**Or:**
- **Windows:** Settings → Apps → Find "InvestPro" → Uninstall
- **Mac:** Applications → Right-click "InvestPro" → Move to Trash
- **Linux:** Application menu → Right-click → Uninstall

### **Chrome Settings Method:**
1. Open Chrome → Settings → Apps
2. Find "InvestPro"
3. Click three dots → Uninstall

## 🔧 Troubleshooting

### **Don't see the Install icon?**
- Make sure you're using Chrome, Edge, or Brave (latest version)
- Try refreshing the page (Ctrl+R or Cmd+R)
- Check if the app meets PWA requirements (HTTPS for production)

### **App not updating?**
- Close and reopen the app
- Or uninstall and reinstall

### **Local Development Setup:**
For localhost, PWA features may be limited. Deploy to a proper domain for full PWA experience.
