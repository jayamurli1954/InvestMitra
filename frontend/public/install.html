📊 Install InvestMitra

Get your investment platform as a desktop application

🎯 Method 1: Chrome Shortcut RECOMMENDED

Works on Windows, Mac, and Linux. Creates a true standalone app.

  1. Click the three dots menu (⋮) in Chrome's top-right corner
  2. Go to "More tools" → "Create shortcut..."
  3. In the dialog, check the box "Open as window"
  4. Click "Create"
✓ Result: InvestMitra opens in its own window with no browser UI. Shortcut appears on Desktop and in Start Menu/Applications.
💻 Method 2: Windows Desktop Shortcut
  1. Right-click on your Desktop
  2. Select New → Shortcut
  3. Paste this as the location:
"C:\Program Files\Google\Chrome\Application\chrome.exe" --app=http://localhost:3000 --window-size=1400,900
  1. Click Next, name it "InvestMitra"
  2. Click Finish
Note: Change localhost:3000 to your actual app URL if different.
🍎 Method 3: Mac Application
  1. Open Automator (Applications → Automator)
  2. Choose "Application"
  3. Add "Run Shell Script" action
  4. Paste this code:
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --app=http://localhost:3000 --window-size=1400,900
  1. Save as "InvestMitra" in Applications folder
  2. Drag to Dock for quick access
⚡ Quick Access Alternative

If you just want quick access without installation:

  1. Press Ctrl+D (Windows/Linux) or Cmd+D (Mac)
  2. Save bookmark to Bookmarks Bar
  3. Enable Bookmarks Bar: Ctrl+Shift+B
